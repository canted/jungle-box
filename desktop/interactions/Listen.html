Jungle Box · Slider combinations

The approved Angle patterns, with changes to Weight, Reach and Reply. Start with Reference, then compare one control at a time before the combined settings. All recordings use the same output gain; quiet settings have not been normalized louder.

Weight changes reinforcement and drive. Reach changes length and blends shuffle cuts. Reply introduces answers progressively, then strengthens the response. Low-Reply clips run longer so you can hear the changing answer frequency.
